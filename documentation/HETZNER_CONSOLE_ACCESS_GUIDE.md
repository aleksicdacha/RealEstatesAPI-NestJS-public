# ✅ How to Access Hetzner Cloud Console (When Already Logged In)

## Good News: You're Already Logged In!

If you're logged into the Hetzner website, you can access the Cloud Console from there.

---

## 🚀 Quick Navigation

### From Hetzner Main Website → Cloud Console

#### Method 1: Direct Navigation

1. **You're currently on:** https://www.hetzner.com (main website)
2. **Navigate to:** https://console.hetzner.cloud (Cloud Console)
3. **Should auto-login** - Since you're already authenticated

**Try this link directly:**
👉 https://console.hetzner.cloud

---

#### Method 2: Through Hetzner Website Menu

If you're on https://www.hetzner.com or https://accounts.hetzner.com:

1. Look for **"Cloud Console"** in the top menu
2. OR click your **account/profile icon** (top right)
3. Look for **"Cloud Console"** or **"Hetzner Cloud"** link
4. Click it - you'll be redirected and auto-logged in

---

#### Method 3: Through Accounts Page

1. You're likely on: https://accounts.hetzner.com
2. Look for **"Products"** section
3. Find **"Hetzner Cloud"**
4. Click it → Opens Cloud Console

## 🔑 Why Different Credentials Don't Work

**Important:** Hetzner has **multiple systems** with potentially different logins:

| System | Purpose | Login Type |
|--------|---------|------------|
| **Hetzner Main Website** | General info, sales | Email + Password |
| **Hetzner Accounts** | Account management, billing | Email + Password |
| **Hetzner Cloud Console** | Manage cloud servers | **SAME credentials** |
| **Robot Console** | Dedicated servers | Different system |
| **StorageBox** | Storage service | Different credentials |

**All Cloud services should use the SAME login!**

## 🔍 Troubleshooting

### Issue: "Already logged in to website, but Cloud Console asks for login"

**Solution 1: Use Same Browser/Tab**
1. **Don't open Cloud Console in a new browser**
2. While logged into Hetzner website, click the Cloud Console link
3. Should auto-authenticate

**Solution 2: Check Session**
1. Make sure you're still logged in
2. Look for your name/email in top right corner
3. If logged out, log back in first

**Solution 3: Clear Cookies and Re-login**
```
1. Logout from Hetzner website
2. Clear browser cookies for *.hetzner.com and *.hetzner.cloud
3. Close browser
4. Open fresh browser window
5. Go to https://console.hetzner.cloud
6. Login with your credentials
```

## 📧 Password Reset (If Still Needed)

If direct navigation doesn't work and you need to login to Cloud Console separately:

### On Cloud Console Login Page:

1. Go to https://console.hetzner.cloud
2. Enter your email (same one you're using on main website)
3. Click **"Forgot password?"**
4. **Check email** for reset link
5. Create new password
6. **IMPORTANT:** This will be your Cloud Console password

### Note About Passwords:

- Hetzner may have recently separated Cloud Console authentication
- Your main website password might be different from Cloud Console
- Reset Cloud Console password specifically if needed

## 💡 Common Scenarios

### Scenario 1: "I only have dedicated servers, not cloud servers"

If you only have Hetzner dedicated servers:
- You might not have Cloud Console access
- You'd use Robot Console instead: https://robot.hetzner.com
- Cloud Console is ONLY for Hetzner Cloud (VPS) servers

**To check:**
1. Look at your invoices - are they for "Cloud" or "Dedicated"?
2. Cloud servers are hourly billing (~€5-10/month)
3. Dedicated servers are monthly (~€30+/month)

### Scenario 2: "I created account but never created a Cloud server"

1. You can still access Cloud Console
2. You'll see empty dashboard
3. Big "Create Server" button
4. This is normal for new accounts
