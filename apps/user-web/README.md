# User Web - Real Estate Platform

User-facing Next.js application for browsing and searching real estate properties.

## Features

- 🏠 Property listings with advanced search
- 🗺️ Google Maps integration
- 🌐 Multi-language support (Serbian, English)
- 📱 Fully responsive design
- 🎨 Modern UI with Tailwind CSS
- ⚡ Optimized performance with Next.js 15

## Development

```bash
npm run dev
```

Open [http://localhost:3002](http://localhost:3002)

## Build

```bash
npm run build
npm start
```
